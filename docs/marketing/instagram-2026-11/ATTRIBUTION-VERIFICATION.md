# Проверка атрибуции обращений Bazaar

Дата: 3 ноября 2026. Рабочая ветка: main по прямому указанию владельца. Релиз в production и отправка изменений на сервер не выполнялись.

## Объём изменения

Первый переход с полным набором UTM сохраняется в first-party HttpOnly cookie на 30 дней, затем сервер связывает источник с успешно созданной заявкой или новым пользователем. Повторное обращение или возобновление регистрации не заменяет исходную метку. Контекст сохраняется на пользователе при создании организации и магазина. Неразмеченные обращения остаются неатрибутированными. Публичная мутация заявки возвращает только подтверждение, без данных существующего обращения.

Колонки JSONB в User и AccessRequest добавляются nullable-миграцией `20261103120000_signup_attribution`. SQL не меняет существующие строки, права, тарифы, остатки и деньги. Контрольная сумма SQL внесена в реестр проверяемых миграций; применение требует отдельного релиза. Интерфейсы политики конфиденциальности обновлены на RU/KG/EN.

UTM считаются неподтверждёнными метками источника, не доказательством оплаты или рекламного клика. Сохраняются только разрешённые короткие названия; полные URL, fbclid и произвольные поля не переносятся. DNT/GPC отключают сбор; API также проверяет отказ. Автоматического подсчёта просмотров, Meta Pixel, CAPI и внешних провайдеров в изменении нет.

## Ограничения и выпуск

Серверная атрибуция начнёт работать на сайте только после отдельно разрешённого развёртывания кода и миграции. Ссылка био сейчас содержит только часть меток; для новой кампании нужен полный комплект из плана. WhatsApp лендинга не переносит UTM: источник разговора учитывается по коду материала или сообщению клиента и отмечается отдельно. Общая ссылка био не позволяет доказать конкретный просмотренный Reels.

Публикация контента отключена по указанию владельца. Визуальный комплект отклонён владельцем; самостоятельная отрисовка и генератор остановлены по прямому запрету. Материалы не финальны. Права публикации не подключены, материалы не отправлялись в расписание. Наличие черновиков и успешных технических проверок не означает, что продвижение или внешнее расписание запущены. Изменения мобильного релиза в общей папке не относятся к этой поставке и сохранены отдельно.
