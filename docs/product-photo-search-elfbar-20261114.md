# Проверка ELFBAR GH23000 разных вкусов

Последующее улучшение с выделением предмета и OCR проверено отдельно:
[новый протокол](product-photo-search-vision-20261114.md). Ниже сохранён исходный результат.

14 ноября 2026, `codex/playground`. Только действующий локальный тестовый магазин,
без production, внешнего поискового API, обучения модели или изменения порога.

## Что добавлено

В `photo-search-browser-shop` организации `photo-search-browser-qa` добавлены пять
отдельных тестовых карточек. Исходный Miami Mint с фотографией пользователя сохранён.
В каждой новой карточке — настоящая фотография физического устройства из
[обзора Андрея Попко / BelVaping от 20 ноября 2024](https://belvaping.com/reviews/odnorazki-elfbar-gh23000-bar-s-ogonkom/).
Это не сгенерированные или перекрашенные варианты одного изображения.

| Вкус | Вид корпуса на фотографии | Тестовый артикул |
| --- | --- | --- |
| Grape Ice | Сиреневый | QA-ELFBAR-GH23000-GRAPE-ICE |
| Pineapple Plums Lime Mint | Оранжевый | QA-ELFBAR-GH23000-PINEAPPLE-PLUMS-LIME-MINT |
| Ice Mint | Бирюзовый | QA-ELFBAR-GH23000-ICE-MINT |
| Peach Mango Watermelon | Оранжевый | QA-ELFBAR-GH23000-PEACH-MANGO-WATERMELON |
| Kiwi Dragon Fruit | Розовый | QA-ELFBAR-GH23000-KIWI-DRAGON-FRUIT |

Из фотографии каждого предмета вырезана прямоугольная область устройства. Цвет,
перспектива и надписи не менялись. Изображения загружены через существующий
`/api/product-images/upload`, карточки созданы через `products.create`. В описании
карточек указан автор и источник. Цена не назначалась, остаток и продажи не создавались.
Клиентские записи и другие магазины не изменялись.

Все фотографии хранятся только в игнорируемых локальных каталогах и локальном
хранилище изображений. В репозитории — URL, контрольные суммы, области вырезки,
скрипт и числовой протокол; сторонние фотографии не распространяются с кодом.
Разрешение на использование этих фотографий в production не устанавливалось.

## Как проверяли

До запуска модели зафиксирован [манифест](../scripts/qa/fixtures/elfbar-photo-search.json)
с 16 исходными изображениями, SHA-256, пятью фотографиями галереи и 11 запросами.
Запросы не добавлялись в галерею. Смена размера или вырезка из той же исходной
фотографии не считалась независимым проверочным снимком.

Проверены отдельно:

1. Две другие настоящие фотографии **Ice Mint** из обзора: стоящий на столе
   предмет и устройство в руке. Для первого запроса выделена область предмета,
   второй снимок подан целиком вместе с рукой и фоном.
2. Пять изображений соответствующих вкусов с
   [официальной страницы ELFBAR](https://www.elfbar.ru/product/gh23000.html).
   Это рекламные изображения производителя, а не фотографии с камеры;
   результаты этой группы нельзя выдавать за точность на снимках пользователей.
3. Четыре изображения похожих **отсутствующих** вкусов с той же страницы:
   Green Apple Ice, Strawberry Banana, Lime Grapefruit Ice, Sakura Grape.

Поиск выполнен через настоящий авторизованный API приложения, текущий PP-ShiTuV2
PPLCNetV2 FP32 + Faiss и действующий порог 0,68. В магазине остаются и предыдущие
открытые тестовые товары: галерея содержит 24 подготовленных изображения, а не
только ELFBAR. Состав галереи, загруженные файлы и принадлежность карточек магазину
проверяются в БД и по контрольным суммам. Ответы не подменялись.

## Результат

| Группа | Запросов | Правильный первым | Правильный в первых пяти |
| --- | ---: | ---: | ---: |
| Отдельные фотографии Ice Mint | 2 | 1 | 1 |
| Изображения производителя для пяти добавленных вкусов | 5 | 4 | 5 |

Все четыре запроса отсутствующих вкусов вернули похожие карточки магазина.
Это выдача кандидатов, а не подтверждение наличия запрошенного вкуса.

| Конкретный запрос | Что вернул поиск |
| --- | --- |
| Ice Mint стоит на столе | Ice Mint первым и единственным |
| Ice Mint в руке | Пустая выдача; нужный товар не прошёл порог |
| Peach Mango Watermelon, изображение производителя | **Pineapple Plums Lime Mint первым**, правильный Peach Mango Watermelon вторым |
| Green Apple Ice, отсутствует | Ice Mint |
| Strawberry Banana, отсутствует | Kiwi Dragon Fruit |
| Lime Grapefruit Ice, отсутствует | Pineapple Plums Lime Mint, затем Peach Mango Watermelon |
| Sakura Grape, отсутствует | Grape Ice |

Есть подтверждённая путаница близких оранжевых вариантов. Изображения, отличающиеся
в основном небольшой надписью вкуса, текущий поиск не различает надёжно. Ручной выбор
по фотографии, названию и артикулу обязателен; первый кандидат не выбирается
автоматически. Наличие одного результата тоже не доказывает правильность вкуса.

Это небольшой диагностический набор, без статистической гарантии качества.
Две независимые фотографии относятся только к Ice Mint. Проверка фотографии
пользовательского Miami Mint со стола здесь не повторялась — такой снимок не сохранён.
Изображение производителя Miami Mint не использовалось как независимый запрос:
оно может совпадать с исходным изображением карточки пользователя.

Для следующего этапа обоснованно проверить выделение области предмета и чтение
надписи вкуса/штрихкода поверх визуальной выдачи. В этом изменении такие механизмы
не реализованы, вывод об их пользе пока является гипотезой.

Полные реальные ответы, порядок карточек и время каждого запроса:
[results.json](benchmarks/product-photo-elfbar-20261114/results.json).

## Повторение и проверки

Скрипт `scripts/qa/product-photo-search-elfbar.mjs` поддерживает:

```sh
node scripts/qa/product-photo-search-elfbar.mjs prepare
node scripts/qa/product-photo-search-elfbar.mjs seed
node scripts/qa/product-photo-search-elfbar.mjs evaluate
```

Для `seed`/`evaluate` нужны переменные `PRODUCT_PHOTO_QA_BASE_URL`,
`PRODUCT_PHOTO_QA_EMAIL`, `PRODUCT_PHOTO_QA_PASSWORD` из уже настроенного локального
аккаунта. Пароль не записывается в репозиторий. Скрипт не читает `.env` и использует
только фиксированную локальную тестовую БД на 55991, проверяет её имя, владельца,
порт, маркер изоляции, организацию сессии и магазин. Внешние адреса приложения
не разрешены. Запускать его против production невозможно без изменения скрипта.

`seed` выполнен дважды: дублей не появилось, исходная карточка не изменилась.
`evaluate` выполняет 11 реальных запросов и дополнительный запрос к другому пустому
магазину: чужие кандидаты туда не попали. Ограничение 12 запросов в минуту
сохраняется; повторный запуск нужно выполнять после освобождения лимита.

`prepare` проверил все 16 исходников; также прошли:

```sh
node --check scripts/qa/product-photo-search-elfbar.mjs
SKIP_DB_TESTS=1 RUN_DB_TESTS=0 pnpm exec vitest run tests/unit/product-photo-search-ui.test.tsx tests/unit/product-photo-search-engine.test.ts
pnpm typecheck
pnpm lint
pnpm i18n:check
```

Два файла unit-тестов: **13 проверок прошли**. Проверки с настоящей БД и моделью —
описанные выше запросы к отдельному локальному магазину; БД не сбрасывалась.
Исходный набор из 55 проверок приложения в этом проходе повторно не запускался.
Приложение, модель и зависимости не менялись, новая production-сборка не выполнялась.

В браузере проверены все шесть карточек и реальная путаница оранжевых вариантов.
На размере 390×844 окно помещается в экран, горизонтального переполнения нет,
длинные артикулы переносятся. Выбор второго результата открыл именно
Peach Mango Watermelon. Новых ошибок/предупреждений консоли во время поиска не было.

Для ручной проверки снимки доступны в `.local/product-photo-search/try-photos/elfbar/`.
Локальный магазин, модель и обработчик изображений оставлены работающими для
проверки с телефона в той же Wi-Fi сети. В production ничего не развёрнуто.
