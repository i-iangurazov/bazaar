# Проверка безопасности PR #8 перед выпуском

Статус успешного задания `codeql` означает завершение анализа, но не отсутствие
предупреждений. Перед слиянием отдельно проверяется результат приложения CodeQL
и все его новые annotations. Правила сканера не отключаются.

Из семи отмеченных в PR предупреждений:

- `js/redos`, `src/lib/baam/companion.ts`: валидация ссылки заменена линейной
  проверкой сегментов. Сохранены ограничения путей, query и разрешённых `%3A`.
  Регрессия включает некорректный путь длиной 100 000 символов и границы маршрутов.
- `js/disabling-certificate-validation`, репетиция отката: клиент доверяет только
  сертификату этой репетиции через `ca`, без отключения проверки TLS/имени хоста.
- `js/bad-code-sanitization`, unit-тест остановки дочерних процессов: путь к
  временному PID-файлу передаётся аргументом Node, вместо интерполяции в код.
- `js/weak-cryptographic-algorithm`, FreedomPay: MD5 является обязательной частью
  внешнего протокола подписи, не хешированием пароля пользователя. Замена на SHA
  сделает запросы несовместимыми с провайдером. Сверено с [официальным протоколом
  FreedomPay Кыргызстан](https://freedompay.kg/docs/gateway-api/intro).
  Используются HTTPS, постоянное по времени сравнение, серверная сверка платежа.
  Приём платежей остаётся выключен до приёмки мерчанта. Классификация: внешний
  протокольный контракт; повторно оценить при изменении API провайдера.
- Второе предупреждение MD5 относится к независимой синтетической фикстуре
  `tests/integration/subscription-payments.test.ts`; настоящего секрета нет.
- `js/xss-through-dom`, email workspace: цепочка заканчивается статическим JSX
  `<img src={src}>`, а не вставкой текста в HTML. React экранирует значение
  атрибута, оно не может добавить HTML/обработчик события. Этот же sink присутствует
  в прежнем main. Классификация данного предупреждения: false positive.
- `js/stack-trace-exposure`, локальный daemon: канал управления — Unix socket,
  защищённый случайным 256-битным `x-local-secret` из приватного manifest 0600.
  Диагностику получает тот же локальный владелец; публичного HTTP endpoint нет.
  Классификация: false positive для предполагаемого внешнего получателя.

Прочие существовавшие в main предупреждения не объявляются исправленными этим
выпуском. Это проверка новых annotations PR, не заявление об отсутствии любых
возможных уязвимостей. Закрытие четырёх классифицированных предупреждений в
GitHub выполняется только с отдельного согласия владельца; обоснования сохраняются
в code scanning. Строгий TLS отдельно проверен настоящим локальным HTTPS handshake:
сертификат репетиции принимается только с явным `ca`; без него запрос отклоняется.

Vercel Preview отказал до компиляции: в Preview не настроен `DATABASE_URL`.
Production проверен отдельно: рабочие DB/Redis, корректная история и ровно пять
одобренных pending-миграций. Production-доступы в Preview не копируются.
Production build и браузерные/DB-проверки исполняются в изолированном CI.
