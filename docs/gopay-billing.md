# GoPay для подписок Bazaar

GoPay принимает разовую предоплату в KGS для существующего расчёта подписок на 1, 6 и 12 месяцев, повышения тарифа и дополнительных лимитов, а также пакетов ответов WhatsApp AI. Каталог тарифов, цены, скидки и защита действующих/пожизненных условий не изменены. Автосписания GoPay не подключаются.

## Протокол и подтверждение

Официальная спецификация: https://doc.gopay.kg/v1/ . Используются POST `/v1/payments`, `/v1/payments/query`; адаптер также поддерживает отмену **неоплаченного** счёта `/v1/payments/cancel`. Это не возврат денег. Публичный v1 не предоставляет API возвратов: их условия и проведение необходимо согласовать с GoPay/банком. Возвраты нельзя изображать завершёнными только по действию в Bazaar.

Test и Live работают на `https://api.gopay.kg`; режим определяется ключом, затем проверяется по `testing_mode` ответа. Устаревший параметр выбора режима не передаётся. Запрос подписывается HMAC-SHA512 от `nonce + "\n" + exactJSON + "\n"`, uppercase hex. Nonce уникален, транспорт ограничен 12 секундами и 64 КиБ, переходы на другие серверы запрещены. Суммы передаются десятичными строками, рассчитываются сервером в тыйынах.

Настоящий Test API 9 ноября 2026 года выдал hosted checkout на `payment.gopay.kg`, хотя примеры спецификации используют `pay.gopay.kg`. Разрешены только эти два точных HTTPS-домена. Адреса с другим доменом, портом, логином или паролем отклоняются.

Счёт сохраняется **до** обращения к GoPay. Номер заказа — 32 hex-символа, полученных из пространства имён продукта и внутреннего номера счёта. Провайдер, заказ, организация, режим и финансовые условия защищены в базе от изменений. API-ключ не сохраняется в счёте: хранится только его SHA256-идентификатор.

`POST /api/billing/gopay/webhook` проверяет исходные байты и подпись отдельным webhook secret. Затем запрашивает окончательное состояние через API. Сверяются заказ, платёж, сумма, KGS и Test/Live. Только подтверждённый `COMMITTED` создаёт оплаченный период или пакет. Возврат браузера на `/billing` ничего не начисляет. Повторы и гонка callback/сверки не дублируют выдачу. Аутентифицированные события других механизмов и неизвестных заказов подтверждаются без изменений доступа.

## Настройки

Секреты вводятся вне Git, не в чат:

```dotenv
BILLING_PAYMENT_PROVIDER=gopay
BILLING_PAYMENTS_MODE=sandbox
GOPAY_API_KEY=...
GOPAY_API_SECRET=...
GOPAY_WEBHOOK_SECRET=...
```

Для локальной ручной проверки Test-ключи находятся в игнорируемом `.env.gopay.local` с правами 0600. Обычный локальный запуск и QA-сборки не подхватывают эти ключи автоматически. Протокольные и интеграционные автоматические тесты используют независимую фикстуру, без обращений к провайдерам.

При смене ключа прежнюю пару можно временно сохранить в `GOPAY_PREVIOUS_API_KEY` / `GOPAY_PREVIOUS_API_SECRET`, пока незавершённые счета старого ключа требуют сверки. Вебхук использует webhook secret организации GoPay; при его ротации согласуйте момент изменения с GoPay.

Новые счета используют выбранного провайдера; существующие маршрутизируются по сохранённому провайдеру. Старые FreedomPay-обработчики и проверка подписей сохранены, даже если GoPay выбран или пока настроен не полностью. Не удалять прежние FreedomPay-ключи до окончания сверки его счетов.

## Уведомления в кабинете GoPay

Events URL: `https://www.bazaar.kg/api/billing/gopay/webhook`.

Достаточно подписки на `payment.committed`, `payment.failed`, `payment.expired`, `payment.cancelled`. Остальные подписанные события безопасно подтверждаются без начислений. Галочки не подключают автосписания, фискализацию, статические QR или управление счетами GoPay.

После публикации обработчика и настройки webhook secret кнопка **Send test** должна получить HTTP 200. Это проверяет доставку `test.ping`, но не доказывает оплату. Для рабочего запуска отдельно проверяются реальный платёж и дальнейшая сверка.

Существующее расписание `/api/jobs/cron/recovery` раз в пять минут проверяет подписки и WhatsApp-пакеты. У WhatsApp восстановлена ранее отсутствовавшая регистрация обработчика в расписании; запросы ограничены по параллельности и времени. Потерянный callback не требует действий покупателя. Подтверждённый ответ `4041` освобождает неизвестный счёт только после минуты ожидания; повтор с тем же ключом не создаёт второй платёж.

## Ограничения запуска

Production остаётся с `BILLING_PAYMENTS_MODE=disabled` до подключения Live и согласования юридических условий. На production Test-платёж не может создать рабочую подписку или пакет ответов. Для проверки настоящего Test использована отдельная одноразовая база, а не данные клиентов.

Для Live нужны активированная организация GoPay, договор/условия банка, действующий счёт ИП в Бакай в выбранной схеме подключения, Live API key/secret и webhook secret. Затем подтверждаются юридические страницы, их контакты и действующие условия возврата; только после этого устанавливаются `BILLING_PAYMENTS_MODE=live`, `BILLING_LIVE_ACTIVATION_CONFIRMED=1` и необходимые юридические настройки. Guard требует опубликованную согласованную оферту и канонический домен. Домашний адрес этой интеграцией не публикуется.

Пять пожизненно бесплатных организаций защищены по прежним идентификаторам: mpo.kg, roksosh, skladondemand, Avant, Catwalk. Ни миграция, ни новая оплата не переписывают их договоры или права.

## Развёртывание и аварийное отключение

Миграция `20261109190000_gopay_billing` добавляет провайдера и номер заказа к двум видам счетов, индексы и защиту финансовых снимков. История получает default FREEDOMPAY. Суммы, периоды, остатки товаров и договоры не пересчитываются. Точный SQL включён в разрешённые production-миграции.

Для немедленного прекращения новых оплат установить `BILLING_PAYMENTS_MODE=disabled`. Проверку уже созданных счетов и webhook secret сохранять: отключение продаж не должно терять оплаченные операции. При откате приложения миграцию и финансовые записи не удалять. Версия до этой интеграции не умеет сверять GoPay; до её возврата остановить новый checkout и завершить сверку GoPay текущим обработчиком либо вести оставшиеся счета отдельно под контролем оператора. Возврат на старую версию нельзя представлять полноценной поддержкой новых GoPay-счетов.
