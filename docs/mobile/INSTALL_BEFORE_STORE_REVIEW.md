# Установка Bazaar до одобрения магазинами

Проверено 3 ноября 2026 года: публичный адрес `https://www.bazaar.kg/dashboard` открывает вход; manifest, service worker и иконки 192/512 доступны по HTTPS. Manifest задаёт `display: standalone`, `start_url: /dashboard`, `scope: /`. Рабочая учётная запись и доступ к магазину нужны как обычно.

Самый быстрый доступный вариант для пользователей — добавить веб-приложение на главный экран. Одобрение магазинов и сертификаты для этого не нужны.

**iPhone / iPad:** откройте [Bazaar](https://www.bazaar.kg/dashboard) в Safari → «Поделиться» → «На экран Домой» → включите «Открывать как веб-приложение», если предлагается → «Добавить».

**Android:** откройте [Bazaar](https://www.bazaar.kg/dashboard) в Chrome → меню ⋮ → «Установить приложение» либо «Добавить на главный экран» → подтвердите установку.

Наличие файлов PWA проверено с сервера; сам диалог установки на физических iPhone/Android в этом сеансе не проверен. Интернет требуется для операций; PWA не даёт права проводить продажи без связи и не подтверждает работу нативных APNs/FCM, сканера или обмена файлами из оболочки Capacitor.

**Android APK для прямой установки собран и подписан:** `artifacts/mobile-release-20261103/builds/Bazaar-1.0.0-1-release.apk` (1.0.0, build 1). Проверены релизный пакет, подпись Bazaar и выравнивание 16 KB. Установка и работа на физическом телефоне ещё не проверены; публичная ссылка на скачивание APK не создана. Перед массовым распространением проверьте вход, сканирование и обмен документами на Android. Для установки файла Android попросит разрешить установку из выбранного источника. Debug APK предназначен только для разработки, AAB напрямую не устанавливается.

Прямой APK подписан локальным upload key, а версия из Google Play — отдельным ключом Google Play App Signing. Они не обновляются друг поверх друга: переход между каналами потребует удаления приложения с потерей локальных настроек/сессии. Серверные записи Bazaar удалять для этого не нужно. Последующие прямые APK должны сохранять тот же ключ и увеличивать номер сборки.

**Нативный Android уже доступен через внутреннее тестирование Google Play:** [принять приглашение](https://play.google.com/apps/internaltest/4701689887089077061). Сборка 1.0.0 (1) опубликована, трек Active; разрешён адрес владельца, добавленный с его согласием. Откройте ссылку под этим Google-аккаунтом на Android, примите приглашение и перейдите к установке. До ревью Google показывает временное имя `kg.bazaar.app (unreviewed)`. Приглашение проверено в браузере, фактическая установка и работа на телефоне ещё не проверены. Эта ссылка не даёт доступ всем пользователям; новых тестировщиков нужно добавить в разрешённый список.

TestFlight пока недоступен: нет аккаунта Apple Developer и iOS archive. Публичный выпуск за один день не подтверждён: проверки аккаунтов, требования тестирования и решения ревью Apple/Google остаются внешними этапами.

Для этого личного аккаунта Google Play требуется закрытый тест минимум с 12 участниками в течение 14 дней подряд, затем заявка на доступ к production. Такой тест не запущен; внутренний трек не заменяет его. Если участников нет, быстрый общий доступ обеспечивается веб-приложением, а прямой APK остаётся отдельным Android-каналом. [Требование Google](https://support.google.com/googleplay/android-developer/answer/14151465).
